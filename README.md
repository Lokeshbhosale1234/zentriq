# Zentriq 💸

A full-stack personal finance management application to track income, expenses, and visualize financial insights.

---

## 🚀 Features

- Add and manage transactions
- Categorize income and expenses
- Real-time analytics dashboard
- Monthly trends and breakdown

---

## 🛠 Tech Stack

**Frontend**

- React (Vite)
- Axios
- Tailwind CSS

**Backend**

- Spring Boot
- REST APIs
- JPA / Hibernate

---

## 📂 Project Structure

Zentriq/
├── Frontend/
├── Backend/

---

## ⚙️ How to Run

### Backend

cd Backend  
mvn spring-boot:run

### Frontend

cd Frontend  
npm install  
npm run dev
